    Как рассчитывается ILU рейтинг

    Начисление баллов

    Баллы показателя = фактический процент × вес / 100. Например, 80% по показателю весом 10,6 дают 8,48 балла.

    Итог = сумма баллов по всем показателям. Веса уже дают максимум 100. Начисления суммируются без промежуточного округления. Итог отображается с двумя знаками после запятой.

    Отсутствие данных
    Если процент действующего показателя нельзя рассчитать, за него начисляется 0 баллов. Вес сохраняется. Такой участок помечается как предварительный. Если есть хотя бы один такой участок, предварительным считается и рейтинг месяца. Подтверждённые 0% сами по себе не дают этого статуса.
    Место участка
    Места сохраняются по прежнему порядку методики 1.2. Участки с равным результатом по прежним весам делят одно место, например 1, 1, 3. После перераспределения у близких результатов порядок мест может отличаться от порядка новых баллов.
    Динамика за месяц
    Изменение баллов — текущий итог минус предыдущий, изменение позиции — предыдущее место минус текущее. Плюс по позиции означает подъём. Для сравнения нужен последний сохранённый снимок непосредственно предыдущего календарного месяца с той же версией методики. При отсутствии снимка или участка в нём, а также при разных версиях показывается прочерк.
